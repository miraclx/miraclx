### Miraculous Owonubi

Systems and protocol engineer. Rust, distributed systems, peer-to-peer networking.

Core engineer on **[NEAR Protocol](https://github.com/near/nearcore)** (80+ merged PRs to
nearcore; creator and lead maintainer of the
[Rust JSON-RPC client](https://github.com/near/near-jsonrpc-client-rs)) and engineering
lead at **[Calimero](https://github.com/calimero-network)**.

Now independent, building **[theia](https://github.com/theia-hq)**: an overlay where you
reach a machine by its public key instead of its address. No accounts, no server in the
middle, authenticated end to end by the key you dialed.

- **[swoosh](https://github.com/theia-hq/swoosh)** reaches any machine by its public key:
  ssh in, send files, forward ports, share access.
- **[bifrost](https://github.com/theia-hq/bifrost)** opens a byte-stream to an ed25519
  identity over a swappable transport (iroh does the NAT traversal).
- **[quirk](https://github.com/theia-hq/quirk)** is a UDP transport built by hand, to learn
  how a modern one works.
